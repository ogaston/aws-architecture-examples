# Static Web Hosting & CDN

This example demonstrates how to deploy a static web application using AWS S3, CloudFront, and Route 53.

## Use case

You want to deploy a static web application to AWS and make it available via a CDN.

## Resources

- S3 bucket for hosting the static web application
- CloudFront distribution for CDN
- Route 53 for DNS
- ACM for SSL/TLS certificate
