Static Web Hosting with CDN

A zero-build single-page app served from object storage and delivered globally via a CDN.

ogaston.com

About

This demo is a single index.html file. Vue is fetched from a public CDN at runtime — no bundler, no node_modules, no build step.

  • Static assets stored in object storage
  • CDN edge locations cache and serve content
  • Client-side routing via URL hash
